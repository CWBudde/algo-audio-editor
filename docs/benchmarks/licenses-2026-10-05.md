# Dependency audit and notice validation — 2026-10-05

Baseline: `0cd729f` plus this Phase 23 working tree. Linux x64, Node 24.12.0,
Go toolchain 1.26.8, installed Electron 44.5.1. This is local source/packaging
evidence, not hosted CI, signed installers or release approval.

The exact-source collection audited 27 selected Go modules plus the toolchain
and 715 distinct external Bun package identities. There are 743 combined
entries: 62 runtime and 681 development. It preserves 866 license/notice texts;
the application notice asset is 272,398 bytes. A separate installed Electron
artifact audit records 779 Chromium notice sections, preserving the original
20,111,209-byte HTML in the installer rather than embedding it into About.
The [audit reports and remediation plans](../licenses/README.md) retain source
limits and the user's confirmed MIT/BSD/Apache-only policy.
