  `test-lint.yml` cover both targets. Exported comments, context-first test

  surround normalization now also asserts the exact rendered frame count.

  RNGs and fixed/temp fixture paths (`G115`, `G404`, `G304`, `G703`). Production
  exceptions are individual documented lines: validated range conversions,
  signed PCM/position wire bits, the checksum mandated by FLAC and seeded audio

  All 16 runnable jobs have timeouts, including dependency drift and release

  `bun install --frozen-lockfile` always runs. Chromium caches use the installed

Local workflow checks verified pins/timeouts/cache invariants, the installed

## Allocation flake

The historical `prepared auto-wah render+reset allocate 1` race-test failure
was **not reproduced or fixed**. The original allocation assertion is unchanged.
These commands passed through `just --command`:

```sh
go -C packages/kernel test -race ./internal/effects \
  -run '^TestEveryRegisteredEffectPreviewPartitionResetAndOfflineExactParity$/auto-wah$' -count=30
go -C packages/kernel test -race ./internal/effects \
  -run '^TestEveryRegisteredEffectPreviewPartitionResetAndOfflineExactParity$' -count=20
```

The isolated 30 repetitions passed in 3.757 s; 20 complete 51-effect catalogue
repetitions passed in 162.573 s. `testing.AllocsPerRun` reads process-global
allocation counters and averages across runs; incidental runtime allocations
remain a possible explanation, not an established diagnosis. R.1 stays open.

## Short-file EOF flake

The historical frame-13-versus-31 snapshot failure was **not reproduced or
fixed**. The existing exact 31-frame cursor/consumption, zero-underrun and replay
assertions are unchanged. Before and after passive diagnostic instrumentation:

```sh
bun run --cwd apps/editor-web e2e e2e/transport.spec.ts \
  -g 'short files' --repeat-each=30 --workers=6
bun run --cwd apps/editor-web e2e e2e/transport.spec.ts --workers=4
```

All 30 unchanged repetitions passed in 22.4 s; all 30 instrumented repetitions
passed in 20.6 s. The full four-case functional transport suite passed in 5.5 s.
These agent sweeps used the existing production build with the edited test
harness; they were not a newly stamped build of the R.1 kernel changes.

`playback-probe.ts` now offers passive capture that retains the hardware rate and
audio graph. `transport.spec.ts` attaches the DOM cursor, device output timestamp,
raw shared counters and consumer sequence coherence on success or assertion
failure. Capture failures become diagnostic text without replacing the original
assertion failure. [One actual final snapshot](r1-eof-2026-10-05.json) retains
cursor/consumed frame 31, zero underruns and coherent consumer counters. This is
passing-run evidence, not a reconstruction of the lost historical trace.
